Weekly Task Tracker

This app is a very simple task tracker, all you do is enter the tasks that need to be done, and create a list. there are options to delete tasks in the lists page. The add task page will ask you if you want to create a new list or add to a current one to keep tasks organized in specific areas.

To run this app locally you need to do the following.

1. Clone the repository. VIA github

2. Install dependencies:
   
   npm install

3. Start it up

    npm start

4. go to localhost:3000
